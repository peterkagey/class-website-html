Tips for writing \(\LaTeX\)

Below is a series of tips for writing \( \LaTeX \), pronounced LAY-teck or LAH-teck, which is the most common way for professionals to typeset mathematics.

Getting started

  1. The easiest way to get started quickly is to use an online \( \LaTeX \) compiler like Overleaf.
  2. To type math in-line, you can type \( x + y \) or $x + y$, which will render as "\( x + y \)." This is typically the way you want to typeset variables and shorter expressions.
  3. To type display style math, you can type \[ \int_{0}^{1} x^2\,dx = ... \] or $$...$$, which will render centered, larger, and on a new line like this: \[ \int_{0}^{1} x^2\, dx = \left. \frac{x^3}{3} \right|_{0}^{1} = \frac{1}{3}. \] This is typically the way you want to typeset equations and longer expressions.
  4. When you're getting started, you'll want to use a template, which you can download. (Alternatively, click below to expand the plain text version.)
    Template for \( \LaTeX \) document 
    \documentclass{article}
\usepackage[margin=1in]{geometry} % set margin size
\usepackage{mathtools, amsfonts, amsthm} % load math symbols
\usepackage{hyperref} % to add hyperlinks via \url{...}
\usepackage{xcolor}   % to add color
\usepackage{graphicx} % to include images
\usepackage{listings} % to include code snippets

  5. As you're getting started, you will have to look up lots of symbols! A good way to find these is by using Detexify to look up your symbol by drawing it!

Whitespace in text

  1. When writing text, the right way to do a line break between paragraphs is to leave an entirely blank line between your paragraphs in the source code.
  2. You can also force a line break with \\, but you very rarely want to do things this way.
  3. If you have an indent at the beginning of a paragraph and want to get rid of it, you can start the line of text with \noindent.

Commands

  1. You can define shortcuts to use, such as \newcommand{\Z}{\mathbb{Z}}, which will replace any use of \Z in your code with \mathbb{Z} to display \( \mathbb{Z} \).
  2. You can even have commands that contain arguments! Annoyed by typing \langle ... \rangle all the time? Write \newcommand{\ang}[1]{\langle #1 \rangle}, where the #1 is the argument, and then \ang{r^2, f} will display as \( \langle r^2, f \rangle \), as desired.

Typesetting math

  1. Want to line up your equals signs? You can do so with the align* environment. 
    \begin{align*}
  (x * y) * (y^{-1} * x^{-1})
  &= x * ((y * y^{-1}) * x^{-1}) \\
  &= x * (e * x^{-1}) \\
  &= x * x^{-1} \\
  &= e
\end{align*}
    This will render as \[ \begin{align*} (x * y) * (y^{-1} * x^{-1}) &= x * ((y * y^{-1}) * x^{-1}) \\ &= x * (e * x^{-1}) \\ &= x * x^{-1} \\ &= e \end{align*} \]
