Symmetry

Many problems can be solved by noticing and exploiting a hidden or non-obvious symmetry. Keep an eye out for places that symmetries might be hiding in the following problems.

Problem 1.

Compute the integral \[ \int_{0}^{\pi/2} \frac{\sin^n x}{\sin^n x + \cos^n x} dx. \]

Exercise 8.7.67, Thomas' Calculus

Problem 2.

If $a, b, c$ be real and positive, prove that \[ \frac{a}{b+c} + \frac{b}{a+c} + \frac{c}{a+b} \geq \frac{3}{2} \]

Problem 15114, The Educational Times and Journal of the College of Preceptors (Solutions)

Problem 3.

Let $X$ be the set of reals except $0$ and $1$. Find all real valued functions $f(x)$ on $X$ which satisfy \[ f(x) + f\!\left(1-\frac{1}{x}\right) = 1 + x \] for all \(x \in X\).

1971 Putnam Exam, Problem B2

Problem 4.

In \(\triangle BAC\), \(\angle BAC=40^\circ\), \(AB=10\), and \(AC=6\). Points \(D\) and \(E\) lie on \(\overline{AB}\) and \(\overline{AC}\) respectively. What is the minimum possible value of \(BE+DE+CD\)?

2014 AMC 12A, Problem 20
