Comments

You can get the \(\LaTeX\) compiler to ignore a line of code by putting % at the beginning of the line. Most text editors (including Overleaf) have a shortcut which will toggle which lines are commented. In Overleaf, the shortcut is Ctrl + / on Windows and ⌘ + / on MacOS.

  1. Add % at the beginning of the line and watch \(\LaTeX\) ignore it.
  2. Use the shortcut described above to toggle the comment off from that line.

TODO notes

Frequently when working on a document, we want to add notes (which we will remove later). My preferred way to do this is to \usepackage{todonotes}.

Make sure that \usepackage{todonotes} appears in your preamble.

  1. Add \todo{Note goes here.} somewhere in your code.
  2. Add \todo[inline, color=blue!10!white]{Note goes here.} somewhere in your code, but make it magenta instead of blue.
