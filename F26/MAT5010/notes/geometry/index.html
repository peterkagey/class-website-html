Page layout

2026-10-06

I tend not to do anything very sophisticated for page layout: I basically only ever change the font size, the margins, and the spacing.

Font size

By default, \(\LaTeX\) only supports a small number of font sizes: 10pt, 11pt, and 12pt. To select this, update the first line of your document: 

\documentclass[11pt]{article}

Margins

To adjust the margins, I use the geometry package: 

\usepackage[margin=1in]{geometry}

Spacing

To adjust the spacing, use \usepackage{setspace} and then use \setstretch{2} to do double-spacing. (But most of the time, you just want to use the default spacing.)
