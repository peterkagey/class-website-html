This week we will discuss whitespace, general environments, and theorem environments.

Whitespace

When writing \(\LaTeX\) in text mode, you should be writing in paragraphs, and paragraphs start with indentation (unless they are the first in a new section.) If you want to start a new paragraph (with a paragraph), just leave an entirely blank line in your source code. In general, you do not usually want to use a double-backslash \\ to force a line break.

There are certain circumstances where you don't want to start a paragraph with an indent, in which case you can start the line with \noindent, but this is somewhat uncommon.

Blank space

Often, you want to force your document to go to the next page, which you can do with \pagebreak.

Frequently when writing assignments, quizzes, or other documents for students, you want a specific amount of blank space. You can achieve this with \vspace{5cm} to get, say five centimeters of blank space.

If you want an entire blank line between paragraphs, use \bigskip, because this will do typographically smart things like automatically adjust when you change font size, or know when it's happening at a page break anyway and not overflow to the next page.

Sometimes you need to add horizontal space. If you need a tiny bit of space, you can use \,, a little bit more, you can use \ (which is \[space]). If you want more than a space-worth of space, you can use \hspace{1cm}. If you just need "a bit more than a space" usually it is a best practice to use something like \quad (or \qquad) for spacing equal to an "1em" (respectively "2em") or the height of the font (respectively twice the height of the font).

Default environments

There are many different environments that we use when writing \(\LaTeX\) to make lists, tables and more.

List environments

In many writing contexts, especially when writing multi-part homework assignments, we want to make numbered lists. We do this with the enumerate, itemize, and descriptionenvironments.

Enumerate

The enumerate environment makes numbered lists using the following syntax: 

\begin{enumerate}
  \item First item in list.
  \item Second item in list.
\end{enumerate}

As you nest these environments, it will automatically change the numbering style from numbers to letters to roman numerals and so on.

Itemize

The itemize environment makes bulleted lists using the following syntax: 

\begin{itemize}
  \item First bullet in list.
  \item Second bullet in list.
\end{itemize}

Again, as you nest these environments, it will automatically change the sub-bullet style.

Tables

In general, making anything but the most basic tables in LaTeX can be annoying, so a lot of people use tools like this LaTeX Tables Generator website. There are different ways of making tables depending on your needs and how much customization you require. You can read the Overleaf documentation on tables for more details.

tabular

When making basic tables that contain text, we often use the tabular environment with syntax like this: 


\begin{tabular}{c|cr}
  row 1 col 1 & row 1 col 2 & row 1 col 3 \\
  \hline
  row 2 c 1 & row 2 c 2 & row 2 c 3
\end{tabular}

This environment requires an argument to tell you how to align the columns. Here c|cr specifies that the first two columns are center-aligned, the third column is right-aligned, and there's a vertical bar between the first and second columns. I bet you can guess how to left-align or add another column.

The columns are marked by &, and the rows are marked by \\, and the \hline puts a horizontal line between the first two rows. The height of the rows and width of the columns in the tabular environment scale to fit the contents.

array

If you want more sophisticated control over your tables, you can use the array package via \usepackage{array} which allows you to access the array environment. This allows you to do things like specify the width of your columns, or have a cell span multiple rows or columns.

matrix

If you want to write matrices, I think the best way is by using the environments you get from the amsmath package via \usepackage{amsmath}: matrix, pmatrix, bmatrix, etc, which all use essentially similar syntax. Make sure you are in math mode (usually display style) when using this environment. 

\[
    \begin{pmatrix}
        a_{11} & 2 \\
        3 & 4
    \end{pmatrix}
    \begin{pmatrix} 1 \\ 3 \end{pmatrix}
    = \begin{pmatrix} a_{11} + 6 \\ 15 \end{pmatrix}
\]

Note that this syntax looks a lot like tabular but with two major differences: you don't specify the column alignment, and the cells are automatically in math mode vs text mode.

Try replacing the pmatrix with pmatrix or pmatrix and see what happens.

Math environments

In addition to the inline math \(...\) and display math \[...\] environments, there are others that serve a variety of needs.

align

To have display math with line breaks (and lined up equals signs), you'll likely want to use the align environment, which requires the amsmath package. The syntax looks like this: 


\begin{align*}
  x &= y \\
  &=z
\end{align*}

Here the equals signs are aligned and everything else that follows is left-justified. Again, the \\ signals a new line, and you can have as many lines as you would like.

What happens if you replace align with align*?

alignat

If you want multiple alignments, you can use the alignat environment, which requires the amsmath package and has similar syntax: 


\begin{alignat}{2}
  2x &+ y  &= 3 \\
  3x &+ 4y &= 726
\end{alignat}

Note that you need to specify how many alignments you're doing (here, 2). Also, you can swap the left/right justification by replacing & with &&. Lastly, check what happens if you replace alignat with alignat*.

equation

The only other math environment I use with any regularity is the equation environment, which is just like the display math environment \[...\], but it will number your equation for future reference.

Sections and subsections

When writing a paper or thesis, usually we break things into sections and subsections. In \(\LaTeX\) we do this with \section{...} and \subsection{...}.

AMS theorem package

For many named math environments, such as theorems, lemmas, propositions, definitions, examples, remarks, etc, we use the the amsthm (pronounced "AMS Theorem") package via \usepackage{amsthm} to specify our preferred styling. (We get the proof environment for free!)

We set this up in the preamble with some code that looks like the following. 


% Default theorem-style
\newtheorem{theorem}{Theorem}[section]
\newtheorem{lemma}[theorem]{Lemma}
\newtheorem{proposition}[theorem]{Proposition}
\newtheorem{corollary}[theorem]{Corollary}

\theoremstyle{definition} % Definition-style
\newtheorem{definition}[theorem]{Definition}
\newtheorem{example}[theorem]{Example}
\newtheorem{exercise}[theorem]{Exercise}

\theoremstyle{remark} % Remark-style
\newtheorem{remark}[theorem]{Remark}
\newtheorem*{note*}{Note}  % unnumbered

There is a lot of customization you can do with your environments: do you want them in normal font, or italicized? Do you want the numbering to indicate the subsection, as in "Theorem 1.4.3" or do you just want the theorems listed sequentially as in "Theorem 35"? Do you want to couple the theorem counter with the example counter, or do you want to have an "Example 3" and a "Theorem 3"? You can customize all of this and more using specifiers like [theorem] or [section] or by preceding the \newtheorem with a \theoremstyle.

What's most important here is knowing that you can create environments named just about whatever you'd like, and you can change the name or the title by editing \newtheorem{environmentName}{Environment title}. If you want things unnumbered, use \newtheorem*. It's also the convention in this case to put an asterisk in your environmentName too.

The proof environment

Importantly, you get the proof environment for free, and it will end with a little square at the end (which you can customize, if you'd like). Put your proofs in proof environments.
