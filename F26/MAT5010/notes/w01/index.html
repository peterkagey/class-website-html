Welcome to MAT 5010! This term we will look at a variety of mathematical typesetting tools, and we will spend a lot of time learning about \(\LaTeX\) (pronounced LAY-teck or LAH-teck), which is the most common way for professionals to typeset mathematics.

Making your first \(\LaTeX\) document

The easiest way to get started writing \(\LaTeX\) documents is by using a tool like Overleaf. If you log in, click "New Project", and select "Blank project", you'll get code that looks like this: 
\documentclass{article}
\usepackage{graphicx} % Required for inserting images

\title{Example Project Name}
\author{Your Name}
\date{August 2026}

\begin{document}

\maketitle

\section{Introduction}

\end{document}
We'll talk about what all of these lines of code mean soon, but for now, you can start by typing Hello MAT 5010! on the line underneath \section{Introduction}. After you hit "Recompile", you should see this text show up under the Introduction header.

Typesetting mathematics

You're not learning \(\LaTeX\) to write prose (although it's very good for that too), you're learning it to write math! There are two main ways to write math: inline math, like \(1 + 1 = 2\) and display math like \[ \int_{x=\varepsilon}^\infty \frac{1}{x^2} dx = \frac{1}{\varepsilon}. \] As a rule of thumb, we use inline math for variables and short expressions, and we use display math for longer or more complex expressions.

There are two ways to type inline math, like \(1 + 1 = 2\) or like $1 + 1 = 2$. The "backslash parentheses" version is considered to be modern and safer, but a lot of people still use the dollar sign version.

Similarly, there are two ways to type displaystyle math: with escaped square brackets, \[1 + 1 = 2\], or with double dollar signs $$1 + 1 = 2$$. Again the square bracket version is more modern, and it's also more common.

How do you find the symbols to use? Of course, you can use tools like Google and LLMs, but it's also worth knowing about Detexify, which allows you to draw a symbol and learn what \(\LaTeX\) command generates it.

Understanding a \(\LaTeX\) preamble

The \(\LaTeX\) preamble is everything that you see before \begin{document}. Here, we'll go through the Overleaf "Blank project" and explain what each line means.

First up is \documentclass{article}. This tells us that we're writing an article-type document instead of a book or a slideshow. This is the main document type you'll be using this term.

Next, we have \usepackage{graphicx} % Required for inserting images, which loads a package which contains commands that allow you to add images to your document. We use packages all of the time to give us new symbols, functions, tools, etc. Everything that comes after the % is a comment, which is meant for a person reading the code, but is ignored by the computer when it compiles the document.

The \title, \author, and \date are just what they sound like, and they show up at the beginning of the document.
