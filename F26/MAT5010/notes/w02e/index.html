Week 2e: Theorems, examples, and remarks

2026-09-01

For many named math environments, such as theorems, lemmas, propositions, definitions, examples, remarks, etc, we use the the amsthm (pronounced "AMS Theorem") package via \usepackage{amsthm} to specify our preferred styling. (We get the proof environment for free!)

The preamble

We set this up in the preamble with some code that looks like the following. 


% Default theorem-style
\newtheorem{theorem}{Theorem}[section]
\newtheorem{lemma}[theorem]{Lemma}
\newtheorem{proposition}[theorem]{Proposition}
\newtheorem{corollary}[theorem]{Corollary}

\theoremstyle{definition} % Definition-style
\newtheorem{definition}[theorem]{Definition}
\newtheorem{example}[theorem]{Example}
\newtheorem{exercise}[theorem]{Exercise}

\theoremstyle{remark} % Remark-style
\newtheorem{remark}[theorem]{Remark}
\newtheorem*{note*}{Note}  % unnumbered

There is a lot of customization you can do with your environments: do you want them in normal font, or italicized? Do you want the numbering to indicate the subsection, as in "Theorem 1.4.3" or do you just want the theorems listed sequentially as in "Theorem 35"? Do you want to couple the theorem counter with the example counter, or do you want to have an "Example 3" and a "Theorem 3"? You can customize all of this and more using specifiers like [theorem] or [section] or by preceding the \newtheorem with a \theoremstyle.

What's most important here is knowing that you can create environments named just about whatever you'd like, and you can change the name or the title by editing \newtheorem{environmentName}{Environment title}. If you want things unnumbered, use \newtheorem*. It's also the convention in this case to put an asterisk in your environmentName too.

Using the environments

Now you can use these environments in the way you might expect: 

\begin{lemma}
  Put your statement of the lemma here.
\end{lemma}

The proof environment

Importantly, you get the proof environment for free, and it will end with a little square at the end (which you can customize, if you'd like). Put your proofs in proof environments.

Week 2 Exercises

(Part 5/5)

In the preamble, use amsthm to define a numbered theorem-style environment, a definition-style environment, a remark-style environment, and one unnumbered environment: 

\newtheorem{theorem}{Theorem}[section]

\theoremstyle{definition}
\newtheorem{definition}[theorem]{Definition}

\theoremstyle{remark}
\newtheorem{remark}[theorem]{Remark}
\newtheorem*{note*}{Note}

In the body of the document, include:

  1. One theorem, followed by a proof environment
  2. One definition
  3. One remark
  4. One unnumbered note (using note*)
