Multiple files

2026-09-29

When making a long document, it can be useful to break your code up into useful pieces. You can do this by putting your code in a partial_file.tex file and then inputting it with \input{partial_file.tex}.

This file should not include a header and should not include \begin{document} or \end{document}, as it's contents will more or less be directly transferred into the corresponding spot in your main document.

When you compile the partial_file.tex in Overleaf, it will show the compilation results for whatever document is designated as your "main" document, which you can set by right-clicking on the filename and selecting "Set as main document".

Make a folder called partials, inside of it, create a new file called filename.tex, and put some code in there such as 
\begin{enumerate}
  \item hello
  \item list
\end{enumerate}
Next include this code in your main document with \input{filename} or \input{filename.tex}.

I sometimes use this technique to break up sections of a paper that I'm writing, but I also will use it to include large TikZ figures that I don't want to see in the source code.

Make sure that in the preamble of your main file, you have \usepackage{tikz} and add a file called tikz_example.tex in your partials folder.

Put the following code in the new file:

\pgfmathsetmacro{\n}{10}
\begin{tikzpicture}
\foreach \x in {0,...,\n} {
  \foreach \y [
    evaluate={\y as \r using random(0,2)},
    evaluate={\y as \p using int(mod(\r+\x+\y,2))},
    evaluate={\y as \c using 200/(\n*sqrt(2))*sqrt((\x-\n/2)*(\x-\n/2) + (\y-\n/2)*(\y-\n/2))} % distance from center
  ] in {0,...,\n} {
    \ifnum \r=2 {
      \draw[line width=10, cyan!\c!red]
        (\x+0.5,\y) -- (\x+0.5,\y+1)
        (\x,\y+0.5) -- (\x+1,\y+0.5)
      ;
    } \else {
        \draw[line width=10, cyan!\c!red, rotate around={90*\r:(\x+0.5,\y+0.5)}]
          (\x,\y+0.5) arc (90:0:0.5)
          (\x+1,\y+0.5) arc (270:180:0.5)
        ;
    } \fi
  }
}
\end{tikzpicture}

Lastly, add \input{tikz_example} into your main file in a figure environment with a caption.

Take a homework assignment from a class that you have typed up, and put each problem in its own file. Make sure that you have a HW_x.tex file designated as your main file on Overleaf (or in whatever text editor you're using) and \input{...} each problem under the appropriate header.

Make an edit to one of these problems and check that it updates your main document.
