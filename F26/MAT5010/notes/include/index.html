Separating content

2026-09-15

When we have long complicated documents, it can be useful to manage your code in many different files instead of one very long file.

Include and input

The most common way to do this is to use \include, which will take \(\LaTeX\) code from referenced file and place it in the referencing file. We can also use \input which will put the referenced file on it's own page in the referencing document.

  1. Make a new file called example.tex, and put the following code in it: 
    We do some basic arithmetic to compute the fifth term of the Fibonacci sequence: \[
  F_3 + F_4 = 3 + 5 = 8 = F_5.
\] We can do similar computations to compute \(F_6\).
    Now in your main document type \include{example.tex}, and see the statement appear.
  2. What happens if you instead type \input{example.tex} in your main document?

When writing documents, I'll frequently use this technique to put figures and other self-contained code snippets into their own file so that my main file remains readable.
