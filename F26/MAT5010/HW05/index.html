HW 5 (Week 5–6)

Due on 29 September 2026 at 2:50PM on Gradescope.

Do one of the following. In particular, do the first one on the list where you expect to learn a new skill.

  1. Set a timer for 30 minutes, and work through the exercises in the BibLaTeX notes.
  2. Read through any of the notes that look interesting to you, and write up the exercises throughout.
  3. Read the Overleaf documentation or any other resource to learn how to do something you want to learn how to do.
  4. Find a classmate exchange feedback on each others' \(\LaTeX\) code, do a small write-up with a before/after submission along with a short reflection.
  5. Come to office hours, ask for feedback on any \(\LaTeX\) you have written, and implement it.

Start your submission with a paragraph articulating what kind of feedback you would most like from me. Try to be as specific as possible. If you don't want feedback, let me know.

Lastly do the following three tasks in order to include your raw \(\LaTeX\) in an appendix at the end of your PDF:

  1. Make sure your \(\LaTeX\) file is named HW05.tex.
  2. Ensure that the package \usepackage{listings} is in your preamble. Below it, put the following options to style it: 
    \lstset{
  basicstyle=\ttfamily,
  numbers=left,
  breaklines=true,
  frame=leftline,
  tabsize=2,
}
  3. Append the following code right before \end{document}: 
    \pagebreak
\appendix
\section*{Source Code}
\lstinputlisting[language=TeX]{HW05.tex}
