In this exercise, you will be starting your proofs portfolio, which you will be working on for the next

  1. Download this proof_portfolio.tex template, upload it in the same folder as this assignment (i.e., the same folder as HW_.tex), make sure it's named proof_portfolio.tex, edit the author, and compile it.
  2. (If you are compiling locally, you can skip this step.) If you are using Overleaf, then once you have compiled the Proofs Portfolio, download the PDF. Next, use the upload feature to upload the PDF to Overleaf, and make sure it's called proof_portfolio.pdf.
  3. In HW_.tex, add \usepackage{pdfpages} to the preamble (the code at the top). Under Exercise 3, type \includepdf[pages=-]{proof_portfolio.pdf}. You should see the section header for Exercise 3 on its own page and the proofs portfolio on the following page.
  4. Copy/paste a proposition/proof that you have written either from this assignment or from a previous assignment. Make sure that it matches the following format, with a carefully written proposition and proof: 
    \begin{proposition}
  Let \(G)\ be a group [...]
\end{proposition}
\begin{proof}
  Suppose that for \(a,b \in G\), [...]
\end{proof}
    I won't be checking the details of the proof this time, I'll only be confirming that you used the template, and that your proposition/proof matches the above.
