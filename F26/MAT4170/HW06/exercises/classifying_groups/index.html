  1. [4] Prove that group isomorphism is an equivalence relation, by showing that it is
    1. Reflexive. (i.e., For all groups \(G\), \(G \cong G\).)
    2. Symmetric. (i.e., For all groups \(G_1, G_2\), if \(G_1 \cong G_2\) then \(G_2 \cong G_1\).)
    3. Transitive. (i.e., For all groups \(G_1, G_2, G_3\), if \(G_1 \cong G_2\) and \(G_2 \cong G_3\), then \(G_1 \cong G_3\).)
  2. [3] Prove the following facts:
    1. Every group has exactly one element of order \(1\).
    2. If \(G\) is a group of order \(p\), where \(p\) is a prime, then \(G\) is a cyclic group (and thus isomorphic to the cyclic group \(C_p\)), and each non-identity element works as a generator of \(G\).
    3. If \(G\) is a group of order \(4\), then \(G\) is not necessarily a cyclic group, but it is necessarily abelian. (Hint: if \(G\) is not cyclic, then use Problem 3.1 from Exam 1.)
  3. [3] Here you will classify all groups up to order 11. You need to prove that all the examples you give are not isomorphic, but you can take for granted that I have given you the correct count.
    It will be useful to remember that the direct product of abelian groups is abelian.
    1. Describe the groups of order \(2, 3, 5, 7, 11\) up to isomorphism. (You did this in the previous part!)
    2. Describe the two groups of order \(4\) up to isomorphism. (You did this in the previous part!)
    3. Describe the two groups of order \(6\) up to isomorphism. (One is not abelian.)
    4. Describe the five groups of order \(8\) up to isomorphism. (Two are not abelian, and you saw one on Exam 1.)
    5. Describe the two groups of order \(9\) up to isomorphism.
    6. Describe the two groups of order \(10\) up to isomorphism. (One is not abelian.)
    7. Without looking, guess how many groups of order \(12\) you think there are, how many groups of order \(14\) you think there are, and how many groups of order \(16\) you think there are. Then click below to find out.
      Groups of order \(n\) up to isomorphism

      The number of groups of order \(n\) up to isomorphism is given by OEIS sequence A000001.

      • There are 5 groups of order 12.
      • There are 2 groups of order 14.
      • There are 14 groups of order 16.
      • There are \(49\,487\,367\,289\) groups of order \(2^{10} = 1024\)
      • Is it an open question how many groups there are of order \(2^{11} = 2048\). It is also an open question whether or not almost all finite groups are of order \(2^k\) for some integer \(k\).
