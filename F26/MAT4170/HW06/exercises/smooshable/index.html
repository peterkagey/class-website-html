In computer programming, a common data type is a string, which is broadly used to represent text, and consists of letters, punctuation, emojis, etc. Some programming languages let you concatenate two strings together with the + operation, so for example, "hello" + "world" = "helloworld", similarly "hello" + "" = "hello". The set of strings under the concatenation operation forms what's called a "monoid," but it does not form a group.

  1. Why doesn't the set of strings under concatenation form a group?
  2. Suppose that we add a new "backspace" character that we'll denote \b, which deletes the character before it so that 
    "hello" + "\bworld" = "hellworld"
    If there is no character before it, it does nothing: 
    "\b" + "hello" = "hello"
    1. Which group axioms does this satisfy, and which does it fail to satisfy? Does the set of strings (with backspace) under concatenation form a group?
    2. Look up the definition of a monoid. Briefly explain why the set of strings (without backspace) under concatenation forms a monoid and why it fails to be a monoid after including the backspace.
