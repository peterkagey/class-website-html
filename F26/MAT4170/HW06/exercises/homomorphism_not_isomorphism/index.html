Do any subset of the following:

  1. [≤4] For each part, give an example of two groups $G_i$ and $H_i$ and a homomorphism $\varphi_i\colon G_i \to H_i$ between them with the following properties.
    1. The homomorphism $\varphi_1\colon G_1 \to H_1$ is an isomorphism.
    2. The homomorphism $\varphi_2\colon G_2 \to H_2$ is neither 1-to-1 nor onto.
    3. The homomorphism $\varphi_3\colon G_3 \hookrightarrow H_3$ is 1-to-1 but not onto. (This is called an embedding but not an isomorphism, and is often denoted with a hooked arrow.)
    4. The homomorphism $\varphi_4\colon G_4 \to H_4$ is not 1-to-1 but is onto.
  2. [≤4] Give four examples of subgroups of $H_i \leq S_5$ that match the following criteria, and for the final three give an explicit embedding (i.e., an injective (1-to-1) homomorphism.)
    1. $H_1 \leq S_5$ that is not a normal subgroup.
    2. $H_2 \leq S_5$ such that $H_2 \cong C_5$ and use this to describe an embedding \[\phi_2 \colon C_5 \hookrightarrow S_5.\]
    3. $H_3 \leq S_5$ such that $H_3 \cong C_6$ and use this to describe an embedding \[\phi_3 \colon C_6 \hookrightarrow S_5.\]
    4. $H_4 \leq S_5$ such that $H_4 \cong C_2 \times C_2$ and use this to describe an embedding \[\phi_4 \colon C_2 \times C_2 \hookrightarrow S_5.\]
