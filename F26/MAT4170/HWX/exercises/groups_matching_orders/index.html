Recall the idea we have often used when differentiating groups up to isomorphism. If we list out all of the orders of the elements, then the groups fail to be isomorphic if the orders fail to match. For example, the dihedral group of the square \(D_4\) has \(1\) element of order \(1\), \(5\) elements of order \(2\), and \(2\) elements of order \(4\), whereas the quaternion group \(Q_8\) has \(1\) element of order \(1\), \(1\) element of order \(2\), and \(6\) elements of order \(4\)—thus these two groups cannot be isomorphic.

This idea does not always succeed in differentiating between non-isomorphic groups—in fact, it fails for some groups of order \(16\).

  1. First, sketch a proof of the fact that if \(\phi\colon G \to H\) is a homomorphism and \(g \in G\) has finite order, then the order of \(\phi(g)\) divides the order of \(g\).
  2. Next, recall that if \(\phi\colon G \to H\) is an isomorphism, \(\phi^{-1}\colon H \to G\) is also an isomorphism. Explain why this implies that for any finite-order \(h \in H\), the order of \(\phi^{-1}(h)\) divides the order of \(h\), and use this to prove that the order of \(\phi(g)\) is equal to the order of \(g\) for every finite-order \(g \in G\).
  3. Compute the orders of all sixteen elements of \(C_4 \times C_4\) and all sixteen elements of \(C_2 \times Q_8\) to show that the groups have the same number of elements of each order.
  4. Prove that the groups \(C_4 \times C_4\) and \(C_2 \times Q_8\) are not isomorphic.
