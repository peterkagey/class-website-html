  1. Draw a Cayley table of \(\mathbb{Z}_2 \times \mathbb{Z}_2\) and use the permutations described by each row to construct an injective group homomorphism (i.e., embedding) \(\Phi\colon \mathbb{Z}_2 \times \mathbb{Z}_2 \to S_4\).
  2. Recall that if \(X\) is a set, then \[ S_X = \{ \ell \colon X \to X \mid \ell \text{ is a bijection}\}. \] Prove that if \((G,*)\) is a group and \(g \in G\), then the map \(\ell_g \colon G \to G\) defined by \(\ell_g(h) = g * h\) (i.e., left multiplication by \(g\)) is an element of \(S_G\).
  3. Prove that the map \(\phi\colon G \to S_G\) defined by \(\phi(g) = \ell_g\) is an injective group homomorphism.
  4. In this part, you will prove that if \(X\) is a set of cardinality \(|X| = n\), then \(S_X \cong S_n\).
    1. Explain how you know that there exists a bijection \(b \colon X \to \{1, 2, \dots, n\}\).
    2. Compose \begin{align*} &f \colon X \to X \\ &b \colon X \to \{1, 2, \dots, n\}, \text{ and} \\ &b^{-1} \colon \{1, 2, \dots, n\} \to X \\ \end{align*} in some order to get a function \(\pi \colon \{1, 2, \dots, n\} \to \{1, 2, \dots, n\}\). (Note that this means \(\pi \in S_n\).)
    3. Use the above construction to use \(b\) and \(b^{-1}\) to define a map \(\psi \colon S_X \to S_n\) such that \(\psi(f) = \pi\). Prove that the map is a isomorphism.
  5. Prove that if \(G\) is a finite group of order \(n\), then there exists an injective homomorphism \(\phi\colon G \to S_n\).
  6. Cayley's theorem. Use \(\phi \colon G \to S_G\) and \(\psi \colon S_G \to S_n\) defined above to construct a map \(\Phi\colon G \to S_n\), and prove that it is an injective homomorphism (also called an "embedding").
  7. Let \(G\) be a group of order \(n\). Prove that there exists a subgroup \(H \leq S_n\) such that \(G \cong H\).
  8. Just because Cayley's theorem gives us an embedding from a group \(G\) of order \(n\) into \(S_n\), this doesn't necessarily mean that we can't embed \(G\) into a smaller symmetric group. While Cayley's theorem proves that we can embed \(D_4\) in \(S_8\) show that we can also embed \(D_4\) in \(S_4\). (Hint: see HW 4 Choice Exercise 10.)
