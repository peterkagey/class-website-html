Let \(\mathbb{Z}_p = \mathbb{Z}/p\mathbb{Z}\), and recall that in HW 6, Exercise 4.2a, you showed that when \(p\) is a prime, every nonzero element in \((\mathbb{Z}_p,+)\) generates the group.
  1. Explain why this shows that for all nonzero elements \(a \in \mathbb{Z}_p\), there exists some \(1 \leq b < n\) such that \(a^b = 1\).
  2. Show why the above argument implies that in the ring \((\mathbb{Z}_p,+,\times)\), all nonzero elements have a multiplicative inverse, and thus forms a field.
  3. Show that if \(n \geq 2\) is not prime, then \((\mathbb{Z}_n,+,\times)\) is not a field.
