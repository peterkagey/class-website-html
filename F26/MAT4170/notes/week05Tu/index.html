Intro to Quotient Groups

We will continue to lay the groundwork to discuss quotient groups, which are a generalization of modular arithmetic.

We care about these quotient groups, because they allow us to ignore information about the group which we might not care about. For instance, in the case of modular arithmetic, we saw examples (such as when we were determining if \({r^k = r^\ell \in C_m}\)) where we didn't care about how many times \(m\) went into \(k\) and \(\ell\), we only cared about the remainder on division.

Here's another example, where we don't care about the particular symmetries of the square, we only care about what it does to a certain pattern.

Suppose that we have a square with a magenta vertical line on top and a green line on the bottom, and we only care about the four possible states that it can be in. While the dihedral group of the square has order eight, \(|D_4| = 8\), here we have a system that only has four symmetries, and moreover \(e\) and \(r^2\) both fix (do nothing to) the decoration of the square, while both \(r\) and \(r^3f\) take the decoration from the first state to the second state.

Later, we will see that this setup can be described by the quotient group that consists of cosets of \(H = \langle r^2 \rangle\): \[ D_4/H = \{H, rH, fH, rfH \}, \] under the (well-defined) operation \[ aH \circledast bH = (a * b)H. \] It turns out that this group is "essentially the same as" (i.e., isomorphic to) both the dihedral group \(D_2\) and the direct product of cyclic groups \(C_2 \times C_2\).

Well-defined operations on cosets

When we were studying the cosets of \(n\mathbb{Z} \leq \mathbb{Z}\), we saw that whenever we chose an element from the coset \(n\mathbb{Z} + a\) and another element from the coset \(n\mathbb{Z} + b\) and added them together, the result was always in the coset \(n\mathbb{Z} + (a + b)\). This allows us to define a group whose elements are cosets, and whose binary operation is \[ \left(n\mathbb{Z} + a\right) + \left(n\mathbb{Z} + b\right) = n\mathbb{Z} + (a + b) \]

However, we have to be careful: this operation is not always well-defined! This means that the output can depend on the names we choose for the coset. Do you see why this creates a problem?

In the following exercise, you will construct an example where you will fail to define a group out cosets because there is not a well-defined binary operation.

Let \(G = D_3\) and \(H = \langle f \rangle = \{e, f\}\).

Give an example of four elements \(a, a', b, b' \in G\) such that \({a' \in aH}\) and \({b' \in bH}\), but \( a' * b' \not\in (a * b)H. \)

A preliminary definition

We take the following as a preliminary definition:

Let \((G,*)\) be a group with subgroup \(H\leq G\). We say that the quotient group \(G/H\) is the group of cosets of \(H\) with the binary operation \[ aH \circledast bH = (a * b)H, \] given that the binary operation is well-defined.

Two notes on this definition:

  1. We usually use the same symbol for the quotient group's binary operation that we used for \(G\), meaning that we write \(*\) as the binary operation instead of \(\circledast\).
  2. Later we will see that the binary operation is well-defined precisely when \(H\) is what's called a normal subgroup, and we will reference this fact in our final definition.
