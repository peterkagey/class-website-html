Rings

Today we will discuss rings, which are an algebraic structure analogous to groups, but with two operations, often denoted \(+\) and \(\times\). Some abstract algebra classes even teach rings before groups, partly because students are "much more familiar with examples of rings (integers, polynomials) than they are with the standard examples of groups (symmetries of simple shapes, permutations)."

In addition to the examples of rings quoted above, it is pedagogically useful to have many examples of rings before we define what a ring is. In the most basic sense, these are sets with something akin to "addition" and something akin to "multiplication" that are compatible in a particular technical sense.

Our first collection of examples are the most classic—however, I warn you to be careful, because there are properties that are true of these rings that are not true of rings in general.

Perhaps the three most classic examples of rings are
  • The integers under standard addition and multiplication: \((\mathbb{Z},+, \times)\).
  • All polynomials in the variable \(x\) with real-valued coefficients, under polynomial addition and multiplication: \((\mathbb{R}[x], +, \times)\).
  • All \(n \times n\) real-valued matrices under matrix addition and matrix multiplication: \((\mathbb{R}^{n \times n}, +, \cdot)\).

Now check that all of the above examples satisfy the following definition.

A ring is a set \(R\) together with two operations \(+\), \(\times\) satisfying the following three axioms:

  1. Under addition, \(R, +\) forms an abelian group with identity denoted \(0_R \in R\).
  2. Under multiplication, \(R, \times\) is closed, associative, and has a multiplicative identity, denoted \(1_R \in R\).
  3. Multiplication is distributive, meaning that for all \(a, b, c \in R\), \begin{align*} a \times (b + c) &= (a \times b) + (a \times c) \\ (a + b) \times c &= (a \times c) + (b \times c). \end{align*}

Before we proceed to some basic propositions and proofs about rings, let's see two more rich examples of rings.

Let \(\phi = (1 + \sqrt{5})/2\) denote the golden ratio, which satisfies the equation \[\phi^2 = \phi + 1.\] Let \(\mathbb{Z}[\phi]\) denote the set of numbers of the form \(a + b\phi\), where \(a, b \in \mathbb{Z}\).
  1. Prove that \(\mathbb{Z}[\phi]\) is forms an abelian group under addition.
  2. Prove that \(\mathbb{Z}[\phi]\) is closed under multiplication, the operation is associative, and there is a multiplicative identity in this set.
  3. Taking for granted that multiplication is distributive on \(\mathbb{R}\), how do you know that multiplication is distributive on \(\mathbb{Z}[\phi]\)?

Next, I will give you a very useful example that ties together group theory and ring theory, but which usually is first encountered in a graduate course.

Let \((G,*)\) be a group. The group ring \(\mathbb{R}[G]\) is the set of "formal linear combinations of \(G\) with real-valued coefficients," which is a fancy way of saying that the elements are sort of like polynomials, but with group elements instead of variables—and when we multiply the group elements, we apply their binary operation.

For instance, if \(G = D_3\), then elements of \(\mathbb{R}[G]\) might look like any of the following: \begin{align*} 3e + 0r - 6r^2 + 0f + 0rf + 0r^2f &= 3e - 6r^2 \\ 0e + 0r + 0r^2 + 0f + 0rf + 0r^2f &= 0 \\ 0e + 0r + 0r^2 - 1f + 0rf + \sqrt{6}r^2f &= -f + \sqrt{6}r^2f \end{align*}

The elements of the group ring add and multiply a lot like polynomials, except for that we use the binary operation of the group instead of multiplication. For instance \begin{align*} &(2e - r) \times (4r^2 + 3rf) \\ &\qquad= 8(e * r^2) + 6(e * rf) - 4(r * r^2) - 3(r * rf) \\ &\qquad= 8r^2 + 6rf - 4e -3r^2f \end{align*}

Determine the additive and multiplicative identities in \(\mathbb{R}[G]\).
