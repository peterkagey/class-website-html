We begin today by talking about Cayley diagrams and conclude by thinking about the matrix representations of groups.

Cayley diagrams

Cayley diagrams (sometimes called Cayley graphs) are a way to visualize group structure by drawing a picture. This can help us think about generators, sets of elements that we can use to build every symmetry. This can also help us to see when two groups are somehow essentially the same or when one group lives inside of another group.

Below is an example of a Cayley diagram for the dihedral group of the square \[ D_4 = \langle r, f \mid r^4 = f^2 = (rf)^2 = e \rangle, \] where the solid green edges represent rotations and the dashed blue edges represent horizontal reflections.

Recalling that our group operation \(*\) is "followed by", we can see by following the diagram (starting from any state at all) that \(r \circ f = f \circ r \circ r \circ r\), and both of these words represent a flip transposing the NW and SE corners of the diagram.

In alignment with graph theory conventions, we call the states vertices, and we call the arrows edges. Here, we have drawn the states as squares with their corners marked, but often we draw our Cayley diagram where the states are simply dots, which agrees with the conventions for drawing vertices in graph theory. We also frequently do not draw the arrowheads on the two-headed edges.

We draw these diagrams by the following steps.

  1. Start by drawing a state and choosing a non-identity element \(g\), draw the the state that results from applying \(g\) along with an arrow from the starting state to the new state.
  2. Continue drawing all new states (and corresponding arrows) that result from repeated applications of \(g\) until you've drawn every state you can reach by applying \(g\).
  3. If you have drawn every possible state, you're done. Otherwise, pick another non-identity element, and a new color for an arrow, and repeatedly apply it (and all of the previous generators you've chosen) to every state until you've drawn all of the states you can reach with these two elements.
  4. Repeat the previous step as many times as necessary until you have reached every possible state. When you're done, there should be an arrow representing each generator going into and coming out of each state. (In the example above, you can see that each state has a green \(r\) arrow and dashed-blue \(f\) arrow going into and coming out of each of the eight states.)

Matrix representations

While we have been thinking about dihedral groups as rotations and reflections, it may have crossed your mind that both rotations and reflections are linear transformations of the plane, and thus they can be represented by \(2 \times 2\) real-valued matrices. This is a profound idea that is studied in group representation theory!

It turns out that every finite group can be written as a collection of real-valued (alternatively complex-valued) square matrices, and this perspective is insightful because it both helps us to see the geometric nature of groups and because it allows us to leverage ideas from linear algebra to give new insights.

Instead of thinking about the dihedral group \[ D_n = \langle r, f \mid r^n = f^2 = (rf)^2 = e \rangle \] as a collection of symmetries, we could instead write every element as a matrix, and describe the composition as matrix multiplication. Let's do it!

Let's write the elements of the dihedral group of the square as linear transformations expressed as real-valued \(2 \times 2\) matrices with respect to the standard basis.
  1. Let \(R\) be the rotation matrix corresponding to a \(90^\circ\) rotation. Write \(R\) explicitly.
  2. Let \(F\) be the matrix corresponding to a horizontal reflection. Write \(F\) explicitly.
  3. Prove that \(R^4 = F^2 = (RF)^2 = I_2\), where \(I_2\) is the \(2\times2\) identity matrix.
  4. Use this to simplify the matrix product \[ R^3FR^4FR^5F^9R^2F^6R^5. \] (Note that we can use the same exact strategy we used when we were thinking about this group abstractly!)

Later on in the course we will learn about the concept of group homomorphisms, which will allow us to define matrix representations more formally.
