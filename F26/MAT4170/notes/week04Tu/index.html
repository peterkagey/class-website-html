Today we are reviewing equivalence relations, and then we will begin discussing cosets, which have a reputation for being difficult for students at first.

Equivalence relations

While reviewing equivalence relations, it's worth remembering why this idea occurs again and again in mathematics: equivalence relations partition a set, meaning that it breaks up the set into parts that are equivalent, such that every element of the set is in one (and only one!) part.

We say that a relation \(\sim\) on a set \(X\) is an equivalence relation if it is
Reflexive.
For all \(x \in X\), \(x \sim x\).
Symmetric.
For all \(x,y \in X\), if \(x \sim y\) then \(y \sim x\).
Transitive.
For all \(x,y,z \in X\), if \(x \sim y\) and \(y \sim z\), then \(x \sim z\).
Let \(X = \mathbb Z\), fix the integer \(m > 1\), and say that \(n \sim r\) if \(n \equiv r \mod m\). Prove that \(\sim\) is an equivalence relation.

Cosets

Let \((G,*)\) be a group, let \(g \in G\), and suppose that \(H \leq G\) is a subgroup.

A left coset of \(H\) is the set of elements \[ gH = \{g * h \mid h \in H\}. \]

A right coset of \(H\) is the set of elements \[ Hg = \{h * g \mid h \in H\}. \]

It is important to keep in mind that a given coset has many different names! In the case of the cosets of the subgroup \(4\mathbb{Z} \leq \mathbb{Z}\), we can say \[ 4\mathbb{Z} + 3 = 4\mathbb{Z} + 7 = 4\mathbb{Z} + (-1) = 4\mathbb{Z} + 403 = \dots \]

Integers mod \(m\) under addition

We usually define the additive group \(\mathbb{Z}/m\mathbb{Z}\) of integers mod \(m\) as a group whose elements are cosets, rather than integers per se.

The additive group \(\mathbb{Z}/m\mathbb{Z}\) of integers mod \(m\) is the set of cosets of the subgroup \(m\mathbb{Z} = \{mn \mid m \in \mathbb{Z}\}\), where the binary operation on cosets (also denoted \(+\)) is defined as \[ (m\mathbb{Z} + a) + (m\mathbb{Z} + b) = (m\mathbb{Z} + (a+b)) \]
Prove that this binary operation is well-defined, meaning that for any choice of \(a' \in m\mathbb{Z} + a\) and \(b' \in m\mathbb{Z} + b\), \[ (a' + b') \in m\mathbb{Z} + (a + b). \] Hint: we proved this in class!
