With the exception of HW0 Choice Exercise 8.2b, we haven't really proven that a binary operation is associative. Prove or disprove whether the following binary operations (inspired by Pinter's Abstract Algebra) are associative on the \(X\). If the operation is not associative, give a counter-example. If it is associative, determine whether or not the operation has a (two-sided) identity element in \(X\).

  1. Let \(X = \mathbb{Z}\) and let \(a \oplus b = a + b + 1\).
  2. Let \(X = \{1,2,3,\dots, 919\}\) and let \(a \ominus b = b\).
  3. Let \(X = \mathbb{Z}\) and let \(a \boxplus b = |a + b|\)
  4. Let \(X = \mathbb{R} \times \mathbb{R}\) and let \[ (a,b) \boxminus (c,d) = (ac-bd, ad + bc) \] (Do you recognize what this secretly is?)
  5. Let \(X = \{-4,-2,-1,0,3,7,8\}\) and let \(a \mathbin\lozenge b = \min(a,b)\)
  6. Let \(X = \mathbb{Q}\setminus\{0\}\) and let \(a \otimes b = \frac{1}{ab}\)
