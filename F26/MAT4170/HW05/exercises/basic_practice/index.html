  1. [≤2] Explain briefly and informally how you know that \[G = \{e^x \mid x \in \mathbb{R} \}\] forms a group under multiplication, and show that it is isomorphic to \((\mathbb{R},+)\) where \(\phi\) is the natural logarithm \(\underbrace{\ln}_\phi\colon G \to (\mathbb{R},+)\).
  2. [≤6] Prove the following statements about structure-preserving maps from the group \((G,*)\) to \((H, \star)\). Recall a map \(\phi \colon G \to H\) is structure-preserving if \[\phi(g_1 * g_2) = \phi(g_1) \star \phi(g_2)\] for all \(g_1, g_2 \in G\).
    1. [1] If \(\phi\colon G \to H\) is a structure-preserving map, then \( \phi(g^{-1}) = \phi(g)^{-1}. \)
    2. [3] Use induction to prove that if \(\phi\colon G \to H\) is a structure-preserving map, then \( \phi(g^n) = \phi(g)^n \) for ...
      1. \(n = 0\)
      2. all integers \(n > 0\)
      3. all integers \(n < 0\)
    3. [2] Prove that if \(\phi\colon G \to H\) is an isomorphism, then \(G\) is abelian if and only if \(H\) is abelian. (Hint: use the fact that if \(\phi\) is an isomorphism, then every \(h \in H\) can be written as \(\phi(g) = h\) for some \(g \in G\).)
  3. [3] Let $G = D_{12}$ and let \(N = \langle r^2 \rangle\).
    1. Write all of the cosets of $N$, compute $|N|$ and $[G:N]$, and write a Cayley table for $G/N$, making sure all of your cells match the names of your row/column headers.
    2. Is \(G/N\) abelian? What is the order of each element of \(G/N\)?
    3. Prove that \(G/N\) is isomorphic to either \(G' = \mathbb{Z}/4\mathbb{Z}\) or \(G' = C_2 \times C_2\) by giving an explicit bijection \(\phi\colon G/N \to G'\) and drawing the Cayley table for \(G'\), and seeing that it matches the Cayley table you found earlier.
  4. [2] Use the fact that you found the multiplicative inverses in \((\mathbb{Z}/15\mathbb{Z})^\times\) in HW 3 and learned about Euler's theorem on HW 4 to solve for \(x\) in the equation \[ 37x + 8^{10} \equiv 17^{81}-x \pmod{15}. \]
