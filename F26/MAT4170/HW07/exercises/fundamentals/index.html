  1. [1] The quiz from Thursday of week 8 asked you to show that the order \(\phi(g)\) divides the order of \(g\).
    Answer key.

    Assume that \(|g| = k\) and \(|\phi(g)| = n\). Since \(\phi\) is structure preserving, \[ e_H = \phi(e_G) = \phi(g^k) = \phi(g)^k, \] and thus \(k \equiv 0 \pmod n\).

  2. [3] Recall that if \((G,*)\) is generated by \(g_1, g_2, \dots, g_n\), then this means that every element of \(G\) can we written as a finite sequence \( g = g_{i_1} * g_{i_2} * \dots * g_{i_m} \) where \({g_{i_k} \in \{g_1, g_1^{-1}, g_2, g_2^{-1}, \dots, g_n, g_n^{-1}\}}\).
    Use induction to prove that if \(N \leq G\) and \(g_i * n * g_i^{-1} \in N\) for all \(1 \leq i \leq n\), then \(N \triangleleft G\). (In other words, we can just check the conjugation property on the generators of G.)
