Exercise 4 [1] (Binary operations)

We use lots of symbols to describe the "binary operation" for group elements depending on the context: $\star$, $*$, $\circ$, $+$, $\times$, juxtaposition1—you name it! These symbols have different meanings depending on the context.

  1. Our first example of a binary operation was $*$, which we read as "followed by." If $f$ is a horizontal reflection (i.e. over the $y$-axis) and $r$ is a $120^\circ$ rotation in the positive (counterclockwise) direction. Write in words what symmetry $r * f$ describes.
  2. Just as easily, we could define a binary operation such as $\star$, and declare that our symbol means "after." In this case, we would read the symmetries "right-to-left." Write in words what symmetry $r \star f$ describes.
  3. When $g$ and $h$ are functions, then function composition gives us a way to combine two functions to get a new function. We denote this function as $g \circ h$. Does $\circ$ behave like "followed by" or does it behave like "after"?
Exercise 5 [4] (Dihedral group)

Recall that we defined the dihedral group in terms of its group presentation: \[ D_n = \langle r, f \mid r^n = f^2 = (rf)^2 = e \rangle. \]

  1. Prove that \(rf = fr^{n-1} \in D_n\).
  2. Use the principle of mathematical induction to prove that \(r^kf = fr^{n-k}\) for all \(0 < k < n\).
  3. Explain why every element of \(D_n\) can be written in the form \(r^kf^\ell\) for \(0 \leq k < n\) and \(\ell \in \{0, 1\}\).

Choice Exercise X [≤6] (\(\LaTeX\) practice) Choose any subset of the following parts (that you don't already know how to do) for \(\frac{1}{2}\) point each.

When you're learning \(\LaTeX\), resources like Google, our class Discord, Detexify, and LLMs can all be very helpful. Here are some things that are good to know:

  1. Write math in a sentence that includes inline math mode, by typing using \(...\) or $...$. Try 
    \(f(x) = 3x^2 - 2x + 4\)
    Write math in a sentence using display-style math mode, by typing using \[...\]. Try 
    \[f(x) = 3x^2 - 2x + 4\]
  2. Write text in italics, bold and underline with
    • \textit{...}
    • \textbf{...}
    • \underline{...}
    Note that this does not work in math mode.
  3. Write a sentence that includes inline math with both a subscript and superscript. For example you can write, "There exists \(g_{10}, g_2 \in G\) such that \(g_{10}^3 = g_2\)" by typing There exists \(g_{10}, g_2 \in G\) such that \(g_{10}^3 = g_2\). What happens if you type g_10 instead of g_{10}?
  4. You can make ordered and unordered lists with the enumerate and itemize environments. Try it out: 
    \begin{enumerate}
\item ...
\item ...
\end{enumerate}
    Do it again but with itemize.
  5. Create a proof environment with \begin{proof} ... \end{proof} and prove that for every integer $a \in \mathbb{Z}$ there exists an integer $b$ such that $a + b = 0$ (or anything else you want to prove).
  6. If you want to make a fraction or square root, you can do that with \frac{3}{1+x} or \sqrt{x^2 + y^2}.
  7. You can type \(\mathbb{Z}\) as \mathbb{Z}, but that's annoying to type all the time, right? In the preamble at the top of your file, define your own command: \newcommand{\Z}{\mathbb{Z}}. Then you can write \Z instead!
  8. The best way to do line breaks in your writing is by just leaving a blank space. Try it!
    A sentence in a paragraph.

A sentence in the next paragraph.
    While \\ will create a line break, it's usually a typographical best practice to only use it in math mode (like in the matrix code below.)
  9. Make sure you have \usepackage{amsmath} at the top of your file, and then modify the following syntax to make a $3 \times 3$ matrix: 
    \[
  \begin{pmatrix}
    a_{11} & a_{12} \\
    a_{21} & a_{22}
  \end{pmatrix}
\]
    currently, it renders like this \[ \begin{pmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{pmatrix} \]
  10. You can include images your document if you \usepackage{graphicx}. Start by uploading the image to the project, and rename the file to something like cool_image.png. Then type 
    \includegraphics[width=0.5\linewidth]{cool_image.png}
    where the width=0.5\linewidth specifies that the image should be half the width of the line. (Note that you should probably put a blank line before this line of code, otherwise the graphics will show up with weird sentence spacing.)
  11. Following on from the above part, the best practice for including graphs and charts is to make them in another program, save them as an image, and include them that way.
  12. Use a tool like Detexify to look up some common symbols. Probably you can guess at some. For instance \(\alpha\) is \alpha, \(\epsilon\) is \epsilon, and \(\pi\) is \pi.
