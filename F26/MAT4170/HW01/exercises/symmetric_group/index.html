In class we used a diagram like this to describe an element of the symmetric group \(S_6\), which describes a way of permuting six elements:

  1. Describe in words how you would explain to an eight year old what the notation \(\pi = 152634\) means.
  2. Write both \(\pi\) and \(\pi^3 = \pi \circ \pi \circ \pi\) in cycle notation.
  3. Let \(\sigma = 143625 \in S_6\). Write \(\pi \circ \sigma\) and \(\sigma \circ \pi\) as words. (Keep in mind that \(\circ\) denotes function application, so we read these expressions right-to-left.)
  4. We say that the order of an element is the smallest (positive) number of times we have to apply it to get back to the identity. (i.e., the least positive integer $k$ such that $\pi^k = e$.)
    What is the order of \(\pi\)?
  5. What is the right inverse of \(\pi\)? (i.e., what is the word \(\tau\) such that \(\tau \circ \pi = e\)?)
  6. What is the left inverse of \(\pi\)? (i.e., what is the word \(\tau\) such that \(\pi \circ \tau = e\)?)
  7. This final part of the question is about $S_5$, the symmetric group on \(5\) letters (here the "letters" are \(\{1, 2, 3, 4, 5\}\)). Can you find a word in $S_5$ with order \(1\)? Order \(2\)? Order \(5\)? Order \(6\)?
