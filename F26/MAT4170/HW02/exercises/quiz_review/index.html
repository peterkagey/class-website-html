  1. The quiz from Tuesday of week 2 asked you to draw some Cayley diagrams.
    Answer key.

    Below is an example of a Cayley diagram for the dihedral group of the square \[ D_4 = \langle r, f \mid r^4 = f^2 = (rf)^2 = e \rangle, \] where the solid green edges represent \(r\) and the dashed blue edges represent \(f\).

    We can also generate \(D_4\) with \(f\) and \(rf\) because we can build \(r = rf * f = r\), and we know we can reach every state with \(f\) and \(r\). If you draw the Cayley diagram (writing the states as dots), it will look like an octagon.
