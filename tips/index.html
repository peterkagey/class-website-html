Tips for MAT 4170

Below is a series of tips for writing \( \LaTeX \), pronounced LAY-teck or LAH-teck, which is the most common way for professionals to typeset mathematics.
  • You do a lot of problem-solving unconsciously when you're sleeping, or watching TV, or going on a walk. Read homework assignments early, so that your brain can do that processing throughout the rest of the week.
  • Use the align* environment for lining up code.
  • In Discord, you should type code in backticks `x_1, x_2`. Otherwise code like this will think you're trying to type in _italics_ because of the two underscores. If you're typing something more significant, put it between triple backticks: 
    ```
\begin{align*}
    r^3f(r^4)fr^5f^9 &= r^3(f^2)r^5f^9 \\
    &= r^8(f^9) \\
    &= (r^8)f \\
    &= (r^4)^2f \\
    &= f
\end{align*}
```
  • Use the enumerate environment (with nesting) for multipart problems.
